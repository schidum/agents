# Contributing

Thanks for helping improve Direct Proportion Parade.

## Before you change anything

- Keep the game simple and friendly for children.
- Preserve the educational goal: direct proportion should be clear and visual.
- Prefer small, easy-to-review changes.

## Suggested workflow

1. Create a new branch for your idea.
2. Make the smallest change that solves the problem.
3. Run the game locally.
4. Update the documentation if the user-facing experience changes.

## Code style

- Keep comments helpful and plentiful.
- Use clear names for game state and helper methods.
- Avoid adding unnecessary dependencies.
- Keep the game accessible and easy to understand.

## Local validation

Run the game from the project root:

```bash
python main.py
```

If you add or change gameplay features, update the README so teachers and parents understand the new experience.
